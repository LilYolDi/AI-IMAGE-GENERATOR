# AI IMAGE GENERATOR

Сайт для генерации и редактирования изображений с помощью ИИ.

## Возможности

- Генерация изображений по тексту.
- Редактирование созданных изображений.
- Несколько форматов изображения.
- Выбор качества.
- Локальная галерея.
- Скачивание и удаление изображений.
- История чата.
- Хранение данных в браузере.

## Установка

Требуется Node.js 20 или новее.

Установить зависимости:

npm install

Запустить:

npm start

Открыть:

http://localhost:3000

## Настройки API

Создать файл .env:

OPENAI_API_KEY=твой_API_ключ
IMAGE_MODEL=gpt-image-1
PORT=3000

Не публиковать настоящий API-ключ в GitHub.

## Размещение на Render

Build Command:

npm install

Start Command:

npm start

В Render → Environment добавить:

OPENAI_API_KEY = твой API-ключ
IMAGE_MODEL = gpt-image-1

## Хранение

Изображения и история чата сохраняются в IndexedDB браузера.

Данные не синхронизируются между устройствами.
Очистка данных сайта в браузере может удалить галерею и историю.

Генерация изображений использует внешний API и может быть платной.
Доступность модели и допустимость запросов зависят от настроек и правил API-провайдера.
